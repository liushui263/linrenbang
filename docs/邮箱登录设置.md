# 邮箱验证码登录：Supabase 后台设置

网站代码已经支持“邮箱收 6 位验证码登录”。站长需要在 Supabase 后台做下面几步，**做完之前邮箱登录会提示发送失败**（Google 登录不受影响）。

## 1. 打开 Email 登录

Supabase → **Authentication → Sign In / Providers → Email**

- **Enable Email provider**：打开
- **Confirm email**：打开（保持默认即可）
- **Email OTP Length**：填 **6**（代码按 6 位写的）
- **Email OTP Expiration**：建议 **600** 秒（10 分钟）
- 页面最上方 **Allow new users to sign up** 要是打开的，否则新邻居没法用邮箱注册

## 2. 改邮件模板，让邮件里显示验证码

Supabase → **Authentication → Emails → Templates**。要改两个模板（新用户第一次登录收到 “Confirm signup”，老用户收到 “Magic Link”）：

**Magic Link** 和 **Confirm signup** 都改成：

- Subject：`邻人帮登录验证码：{{ .Token }}`
- Body（HTML）：

```html
<div style="font-family:-apple-system,Helvetica,Arial,'PingFang SC','Microsoft YaHei',sans-serif;max-width:420px;margin:auto;padding:24px;color:#111">
  <h2 style="margin:0 0 12px">邻人帮 · 登录验证码</h2>
  <p>你的验证码是：</p>
  <p style="font-size:32px;font-weight:bold;letter-spacing:8px;margin:12px 0">{{ .Token }}</p>
  <p>回到邻人帮登录页输入这 6 位数字即可，10 分钟内有效。</p>
  <p style="color:#666;font-size:13px">在电脑上？也可以直接
    <a href="{{ .SiteURL }}/auth/callback?token_hash={{ .TokenHash }}&type=email">点这里登录</a>。
  </p>
  <p style="color:#999;font-size:12px">不是你本人操作？忽略这封邮件就行。<br>Linren Bang sign-in code: {{ .Token }}</p>
</div>
```

说明：
- `{{ .Token }}` 就是 6 位验证码，**一定要有**。
- 链接用 `token_hash` 格式，不依赖浏览器，在微信里点开也能登录。不要用默认模板里的 `{{ .ConfirmationURL }}`：那个在微信里点开常常失败。

## 3. 网址设置

Supabase → **Authentication → URL Configuration**

- **Site URL**：`https://linrenbang.com`
- **Redirect URLs** 里有这几条（Google 登录时可能已经加过）：
  - `https://linrenbang.com/**`
  - `https://www.linrenbang.com/**`
  - `http://localhost:3000/**`（本地开发用）

## 4. 换一个发信服务（强烈建议，免费）

Supabase 自带的发信服务**每小时只能发 2 封左右**，而且只是演示用，邮件容易进垃圾箱。上线前换成自己的 SMTP。推荐 **Resend**（每月 3000 封、每天 100 封免费）：

1. 去 resend.com 注册 → **Domains → Add Domain** → 填 `linrenbang.com`
2. 按它给的 DNS 记录（SPF、DKIM 几条 TXT/MX）到域名服务商那里添加，等它显示 Verified
3. **API Keys → Create API Key**，复制下来
4. 回 Supabase → **Authentication → Emails → SMTP Settings** → 打开 **Enable Custom SMTP**：
   - Sender email：`no-reply@linrenbang.com`
   - Sender name：`邻人帮`
   - Host：`smtp.resend.com`
   - Port：`465`
   - Username：`resend`
   - Password：刚才的 API Key
5. 存好后，到 **Authentication → Rate Limits** 把 “Rate limit for sending emails” 调到每小时 30～100 封

其他可选：Brevo（每天 300 封免费）、Amazon SES（最便宜，但开通麻烦）。

## 5. 测试

用一个从没登录过的邮箱（比如 QQ 邮箱、163、Outlook 各试一个）在 `/login` 发验证码 → 输入 → 应该跳回原来的页面并已登录。QQ / 163 如果收不到，先看垃圾箱；换了 Resend 并验证域名后通常就好了。

## 以后加 “通过 Apple 登录”

代码已经留好位置，按钮默认隐藏。开通步骤：

1. 需要 Apple Developer 账号（每年 99 美元）。
2. 在 Apple Developer → Certificates, Identifiers & Profiles：建一个 **Services ID**（勾 Sign in with Apple，Return URL 填 Supabase 给的 `https://<项目>.supabase.co/auth/v1/callback`），再建一个 **Key**（勾 Sign in with Apple），下载 .p8 文件。
3. Supabase → Authentication → Providers → **Apple**：打开，填 Services ID、Team ID、Key ID 和 .p8 生成的 secret（Supabase 页面上有生成工具）。注意这个 secret **每 6 个月要重新生成一次**。
4. Vercel 环境变量加 `NEXT_PUBLIC_AUTH_APPLE=1`，重新部署，登录页就会出现黑色的 “通过 Apple 登录” 按钮。

提醒：用户选 “隐藏我的邮件地址” 时，我们拿到的是 `xxx@privaterelay.appleid.com` 转发地址；同一个人用 Apple 和用邮箱登录会是两个账号。
